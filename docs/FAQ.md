# LuckyBox FAQ

## What is LuckyBox?

LuckyBox is an Android code editor and Web DevTools workspace maintained by GenzPx.

## Where can I download LuckyBox?

Use the signed APK from the repository's Releases page.

## Does LuckyBox contain ads, billing, or telemetry?

No. LuckyBox removes advertising, Google Billing, Google Play Services, Firebase, and application telemetry.

## Where is project data stored?

Project locations are selected through Android storage access. Local profile settings and application preferences remain on the device.

## Does LuckyBox require an account?

No. The profile feature is local-only and does not authenticate against a server.

## How do I report a bug?

Use the repository bug-report form and include the LuckyBox version, Android version, WebView version, reproduction steps, and relevant logs.

## Why is a feature marked as planned?

LuckyBox is modular. Features are introduced in stages and remain lazy-loaded to protect startup performance.

## Can I update an existing installation?

Yes, when both APKs are signed with the same LuckyBox release key and the new version code is higher.
